# App aus Onlineshop

Minimale Website: weiße Startseite mit Footer (Impressum, AGB, Datenschutz).

## Lokal ansehen

```bash
cd appausonlineshop
python3 -m http.server 8080
```

Dann [http://localhost:8080](http://localhost:8080) öffnen.

## Auf Render deployen

1. Repo mit `main` verbinden.
2. Render → **Static Site** → **Publish directory:** `.`
